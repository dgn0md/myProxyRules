# 模块化与动态规则集开发原则

本页固定本项目的模块边界、规则来源选择和维护方式，与 [仓库维护约定](../AGENTS.md)、[国内 DNS 白名单维护原则](dns-whitelist.md) 一同执行。后续新增服务、修正漏匹配、调整规则源和编写模块测试均以这些原则为前提。

## 按功能与集合组织模块

- 模块按服务类别、厂商或明确的路由用途组织，以声明式的 provider、出口、集合关系和优先级表达行为。不要为每个业务域名、测试端点分别建立模块或配置分支。
- 相同用途复用现有开关。阿里、百度、B站、字节、运营商、华为云、京东、网易、腾讯、小米等国内服务路由统一由 `国内服务优先直连` 控制，不为每个厂商增加独立开关。
- 路由与 DNS 授权属于不同功能边界。统一国内服务路由开关不合并或替代默认启用的 `dns_domestic_cdn`、`dns_microsoft_cdn` 集合边界。
- 函数与文件拆分须服务于实际复用或清晰的职责边界。移除专用设计时，同时删除无用接口、导出、调用、独立文件和文档引用；不要留下空入口、占位实现或仅供未来使用的包装层。必要的内部复用不等于新增公共接口。

## 优先复用现有上游动态规则集

1. 出现漏匹配时，先核对请求的实际域名、运行规则版本与命中结果，再查现用 Bett Rules、Sukka、MetaCubeX 上游的可用分类。
2. 实际读取上游成员，检查目标覆盖、海外业务、共享云/CDN、广告与其他专用服务的重叠。集合名称或厂商归属不足以决定直连或国内解析。
3. 优先选择边界合适的现有上游集合；需要排除子集时，在内核中用集合关系表达，例如“厂商集合且不属于同源海外子集”。不能将整个厂商全量集合无条件视为国内服务。
4. 现用上游不能满足范围要求时，再评估其他维护中的动态来源。记录来源、格式、实际覆盖与缺口，不以扩大整家厂商、公共云或整个 `cn` 集合来掩盖缺失。

海外子集只表示上游已经标注的成员。排除它不保证剩余成员全都位于大陆或适合直连；保留专用服务优先级，并如实说明分类限制。

## 成员更新交给客户端

- 客户端通过 HTTP rule provider 直接更新上游，沿用每日 `interval: 86400`。不在本仓库复制、手工维护、筛选合并或重新发布一套同用途成员清单。
- 构建工具与 GitHub Actions 负责从唯一脚本来源生成配置、摘要和 CDN 副本，不接管上游成员的日常更新。
- 原生验收可以下载、解码规则快照，但这些内容只用于验证，保存在忽略的临时目录，不进入客户端配置或发布产物。

## 精确例外必须有功能依据

动态集合优先，不默认采用逐域名打补丁。现有 Apple 精确端点、协议端点及其他已明确要求的专项例外继续按各自约定维护；确需新增精确例外时，应说明动态集合为何不能正确表达、例外范围与优先级，并保留对应回归。不得仅为使某个测试页面显示预期出口而添加业务域名规则。

此原则不要求删除现有有明确功能依据的精确规则，也不将新模块限制扩展为对历史测试的机械改写。

## 路由与 DNS 分别验收

- 国内服务补充模块排在现有专用服务规则之后、国外域名与 IP 兜底之前；保留 Apple 精确例外与必须代理服务的优先级。
- 明确目标为 `直连` 的域名规则和动态 domain/classical 集合使用同谓词的国内 DNS policy；仅因 IP 兜底而直连的未知域名不自动切换解析器。代理服务 DNS policy 经对应服务组选择出口。国内服务集合的 policy 随 `国内服务优先直连` 开关启停；有同源 `@!cn` 的 11 组按 `domestic AND NOT domestic_noncn` 匹配，百度没有对应子集，按完整集合匹配。`geolocation-cn` 成员另有独立国内加密 DNS policy。这些 policy 不改变 Fake-IP 过滤。不得通过通用 `direct-nameserver` 或故障回退扩大授权。
- 关闭模块控制开关后，清理模块规则及未被其他功能引用的 provider；保留仅由 DNS 或其他功能使用的依赖。国内总开关下既有 Apple 专项行为仍按原约定执行。
- 新增模块的原生测试从实际动态快照提取集合内、排除子集样本；集合外使用合成域名，不维护独立业务域名清单或专用采样导出接口。测试要验证集合关系、开关和优先级，而非逐项复制生产规则。
- 行为改动执行配置、生成一致性及可用的原生检查，覆盖全量/极简、静态/展开和统一开关。文档改动检查链接与原则一致性，不重复声称完成网络实测。

规则源与更新地址见 [规则来源说明](rule-sources.md)，验证方法见 [验证说明](validation.md) 和 [测试说明](../Test/README.md)。
